# Hiddenite

Hiddenite is a web-based audio player.
It is focussed on providing a listening experience which can be provided to and/or contributed by multiple people.

It can be used locally, as a regular audio player, or it can be run on a server somewhere, allowing multiple people use a centrally managed audio player.
Moreover, it has the functionality to use and add songs from streaming platforms like YouTube, because nowadays not everyone is able to buy and obtain their music locally.

This project started because I wanted something like Spotify Jam that is open-source and can be self-hosted, that is also complex enough to allow you to mix multiple pieces of audio useful for DnD sessions, and that can serve as my everyday audio player.
